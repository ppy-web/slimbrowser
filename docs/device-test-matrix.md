# SlimBrowser 设备测试矩阵

本矩阵配合设置页“手工测试工具”中的“打开本地兼容性测试页”使用。该页位于应用 assets，因此不依赖公网。

| 场景 | 操作 | 预期结果 |
| --- | --- | --- |
| URI 兼容 | 打开本地页中的 HTTP、HTTPS、邮件与自定义协议 | 网页加载，或交给系统处理器；没有处理器时提示且应用存活 |
| 长按 | 长按链接和图片 | 显示打开、复制、分享菜单 |
| 上传 | 点击文件选择框并取消/选择文件 | 网页收到结果，取消时不崩溃 |
| Blob 下载 | 点击“生成并下载 Blob 文本” | 下载成功，或显示明确的站点兼容性结果 |
| 错误恢复 | 在手工测试工具中预览离线/HTTP/Renderer 项并点击重试 | 错误页可读，重试或返回不会崩溃 |
| 隐私会话 | 开启隐私模式后浏览并正常退出 | 不新增历史/会话，若开启退出清理则 Cookie、缓存、存储被清除 |

最低设备矩阵为 API 26、API 31+ 和当前目标 API。另需在横屏、手势导航、大字体及 TalkBack 下完成同一组检查。
