# silmbo 图标候选

这些 PNG 是启动图标候选，当前仅用于预览，应用仍使用原来的 `ic_browser`。

- `silmbo-cloud.png`：睡眠云朵 + 浏览器窗口，清爽安静
- `silmbo-cat.png`：奶油猫咪 + 浏览器窗口，温暖可爱
- `silmbo-cat-line-v2.png`：去掉浏览器框架的猫咪简笔画，融入 `Silmbo` 的字母曲线
- `silmbo-cat-line-v3.png`：将背景改为淡蓝色的猫咪简笔画版本
- `silmbo-frog.png`：青蛙 + 桃色浏览器外壳，活泼明亮
- `silmbo-whale.png`：小鲸鱼 + 浏览器窗口，柔和治愈
